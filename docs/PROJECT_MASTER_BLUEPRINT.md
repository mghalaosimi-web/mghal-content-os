# M.GH.AL — AI Content Automation System
## الوثيقة الرئيسية لدراسة المشروع وتخطيطه وتنفيذه وتسليمه

- **معرّف المشروع:** MGHAL-CONTENT-OS
- **اسم المستودع:** `mghal-content-os`
- **الإصدار الوثائقي:** 1.0 — Project Master Blueprint
- **تاريخ إعداد الوثيقة:** 27 أكتوبر 2026
- **نوع المشروع:** نظام شخصي لأتمتة إنتاج المحتوى وإدارته ونشره بالذكاء الاصطناعي
- **المالك:** M.GH.AL
- **بيئة التنفيذ:** Antigravity IDE
- **لغة النظام الأساسية:** العربية، مع دعم كامل لاتجاه RTL
- **المنصات المستهدفة:** فيسبوك (Facebook)، إنستغرام (Instagram)، تيك توك (TikTok)
- **منصات مستبعدة نهائياً:** واتساب (WhatsApp) وجميع حالاته مستبعدة كلياً من نطاق المشروع.

---

## 1. الملخص التنفيذي
نظام متكامل يحمل هوية M.GH.AL، يعمل بوصفه مركزاً ذكياً لإنتاج المحتوى الرقمي وإدارته وأتمتة نشره.
يجمع مسارات العمل التالية في مكان واحد:
1. توليد الأفكار والنصوص العربية المخصصة لكل منصة.
2. استوديو الصور وتوليد الخلفيات وتركيب النصوص العربية عليها برمجيًا.
3. استوديو الفيديو وتجميع المشاهد والصوت والترجمة عبر FFmpeg.
4. لوحة تحكم عربية RTL لإدارة المسودات والموافقة والاعتماد.
5. جدولة ونشر رسمي عبر واجهات المنصات المعتمدة (Facebook, Instagram, TikTok).
6. سجل كامل للعمليات (Audit Log) والتحليلات دون ادعاء بيانات وهمية.

---

## 2. المنصات المستهدفة وحدودها
- **Facebook:** منشورات نصية، صور، فيديو، جدولة، وإحصاءات عبر واجهات Meta Graph API الرسمية.
- **Instagram:** منشورات صور، فيديوهات، Reels، وسوم، وجدولة للحسابات الاحترافية (Creator/Business).
- **TikTok:** فيديوهات عمودية ووصف مخصص عبر TikTok Content Posting API الرسمية.
- **WhatsApp:** مستبعد نهائياً دون أي تكامل أو جداول.

---

## 3. المعمارية والتقنيات الأساسية
- **الواجهة والخادم:** Next.js (App Router) + TypeScript (strict mode) + Tailwind CSS
- **قاعدة البيانات وORM:** PostgreSQL + Prisma ORM (v7.10.1 مع PrismaPg Driver Adapter)
- **التحقق من البيانات والأمان:** Zod للتحقق من البيئة ومدخلات المحتوى
- **الاختبارات:** Vitest + ESLint
- **محرك الذكاء الاصطناعي (المرحلة القادمة M002):** Gemini API عبر طبقة تجريد مستقلة `AIProvider`
